# West Africa Expo Hub

Create a world-class corporate exhibition website similar to what would be expected from a major international trade fair.

The visual style must feel:

* Professional
* Industrial
* Agricultural
* Investment-focused
* Government-friendly
* Premium B2B
* Clean and modern

Do NOT create a startup SaaS design.

Avoid:

* Purple gradients
* Blue-purple AI colors
* Neon effects
* Glassmorphism
* Floating blobs
* Emoji icons
* Italic fonts
* Cartoon illustrations
* Unrealistic AI-generated imagery
* Generic tech startup aesthetics
* Excessive shadows
* Excessive rounded corners

Color System:

Primary:

* Deep Agricultural Green (#0B7A3E)

Secondary:

* Energy Gold (#F4B400)

Supporting:

* White
* Charcoal (#1B1B1B)
* Light Stone Gray (#F5F5F2)

Use color sparingly.

Typography:

Headings:

* Montserrat
* Poppins
* Inter

Body:

* Inter
* Source Sans Pro

Use strong uppercase section titles.

Never use italic text.

Layout Style:

Build the website as a storytelling experience with large sections.

The homepage should contain:

1. Hero Section
2. Expo Introduction
3. Industry Sectors
4. Special Feature Zones
5. Why Exhibit
6. Target Trade Visitors
7. Key Objectives
8. Strategic Positioning
9. Event Information
10. Contact and Sponsorship

Use large spacing and clean grids.

3D Effects:

Use CSS-only 3D effects.

Examples:

* Layered cards
* Depth-based hover interactions
* Parallax scrolling
* Floating image panels
* Perspective transforms
* Multi-layer backgrounds

Do not create gimmicky animations.

Animations:

Use subtle motion only.

Examples:

* Fade-up on scroll
* Staggered reveal
* Slow parallax movement
* Hover elevation
* Image depth shifts
* Number counters

Animation timing:

* 0.4s to 0.8s
* Ease-out
* Smooth and professional

No bouncing animations.
